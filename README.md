# zero-sum-ramsey-2k3
This repository contains the verification code and CNF encoding establishing the exact zero-sum Ramsey number R(2K_3, Z_3) = 8, addressing Problem 4 from Caro and Mifsud (arXiv:2502.03864). The result proves that adding a second disjoint triangle reduces the surplus from +8 (for K_3) down to +2 (for 2K_3), matching the universal upper bound for acyclic forests. The repository includes verify_2k3.py, which verifies the analytical K_7 lower bound and uses Z3 to refute K_8 in under 0.2 seconds, and 2k3_k8.cnf, the exact DIMACS CNF instance with 252 variables and 2,689 clauses. To reproduce the proof, install the solver via "pip install z3-solver" and run "python verify_2k3.py". The CNF file can also be verified independently with any standard SAT solver like CaDiCaL.
